This repository contains data and trained models for predicting molecular properties of organic emitters using machine learning.

-nfa_data.csv
  Dataset containing NFA molecular structures and associated properties.

-tadf_data.csv
  Dataset of TADF molecules with HOMO, LUMO, and related properties.

-generated.csv
  Final dataset of the generated molecules.

-*.pkl
  Saved trained models (HOMO, LUMO, wavelength, S1 and T1.).
